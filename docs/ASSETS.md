`public/assets/learning-scene.png` was created in one built-in ImageGen request (no owner API key, no CLI fallback). Generation brief:

> One standalone square premium bright 3D learning scene matching the supplied reference's visual style. A young adult learner with dark wavy hair, blue hoodie and blue over-ear headphones speaks to a desk microphone beside a silver unbranded laptop, an open notebook, stacked blue/coral books, a floating blue “Hello!” speech bubble, globe and letters. Soft white/pale icy blue seamless background, crisp dimensional materials, warm lighting. No webpage UI, navigation, marketing headlines, fake statistics, logos or watermarks. Preserve supplied logos separately, unchanged.

The result was copied into the project from the generated artifact. Fonts use device-local fallbacks; icons are Lucide React. The notebook is selectable HTML/CSS with interactive correction buttons, not a generated image. Pointer motion is a small translation of the hero scene, disabled on touch and reduced-motion devices.
